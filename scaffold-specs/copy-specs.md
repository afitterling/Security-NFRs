# Prompt: Copy Specs into a New Spec Folder

When I ask you to set up specs for a project, follow this workflow:

1. **Ask for the source.** Prompt me for the source folder `X` (the path to copy specs *from*). I'll give it to you.

2. **Read and list the sources.** Read the contents of folder `X` and present me a list of the available specs/files found there.

3. **Let me select.** I'll tell you which sources I want — I can select any subset, or all of them.

4. **Create the destination.** Create a new `spec/` (specs) folder as the destination.

5. **Copy.** Copy the specs I selected from folder `X` into the new destination `spec/` folder.

Do not copy anything until I've confirmed my selection. Always read and show me what's in the source folder first so I can choose.
