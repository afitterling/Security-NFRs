# Privacy & data protection (`PRIV`)

Requirements for handling personal data lawfully and minimally across all apps.
Several apps target EU users, so GDPR/DSGVO is the baseline, not a regional extra.

| ID | Title | Status |
|----|-------|--------|
| [PRIV-001](PRIV-001-data-minimization-and-retention.md) | Data minimization & retention | Adopted |
| [PRIV-002](PRIV-002-gdpr-dsgvo-user-rights.md) | GDPR/DSGVO user rights | Adopted |
| [PRIV-003](PRIV-003-tracking-consent-att.md) | Tracking consent (App Tracking Transparency) | Proposed |

The `/privacy` **route** itself is specified in
[PAGE-001](../pages/PAGE-001-privacy-route.md); the specs here are the
cross-cutting data-protection requirements its copy has to be true to.

**Retired ID:** `PRIV-004` was the bundle-local draft of that route spec. It was
renumbered to `PAGE-001` and **MUST NOT** be reused.
