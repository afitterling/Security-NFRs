# App Store IAP Setup — API-Driven Recipe

Stand up **auto-renewable subscriptions** for an iOS app entirely through APIs —
no clicking through App Store Connect or the RevenueCat dashboard for the parts
that can be automated — then surface **per-country prices** on a Remix/CloudFront
landing page.

This is a reusable, parameterized recipe. `threethings` (bundle `tech.sp33c.three`)
is the worked example throughout; substitute your own bundle id, prices, and
RevenueCat project to reuse it.

> Status: **proven**. Executed end-to-end for `threethings`: two subscriptions
> created, priced in all 175 App Store territories, 7-day trials in every
> territory, RevenueCat products/entitlement/offering wired. Remaining manual
> bits are called out under *Open items*.

## What the recipe achieves

1. Create a subscription group + monthly & annual auto-renewable subscriptions via
   the **App Store Connect REST API**.
2. Set the price in a base territory, then **equalize to all ~175 territories**
   (Apple does *not* do this automatically over the API).
3. Add a **7-day free trial** in every territory.
4. Add the localizations needed to leave `MISSING_METADATA`.
5. Wire **RevenueCat** (app → products → `premium` entitlement → offering packages)
   via the v2 API, non-destructively alongside sibling apps in the same project.
6. Publish a **per-country price table** to the landing page and render the
   visitor's local price using the `CloudFront-Viewer-Country` header.

## Decisions (locked)

- **Plans:** monthly **and** annual auto-renewable, same `groupLevel` (crossgrades,
  so users can switch monthly↔annual without up/downgrade proration weirdness).
- **Base price:** territory **DE / EUR**, **€0,99/month** and **€12,99/year**.
- **Worldwide pricing:** equalize the DE base across **all territories** via the
  price point `/equalizations` relationship.
- **Free trial:** **7 days** (`FREE_TRIAL`, `ONE_WEEK`, 1 period) in **every** territory.
- **Product IDs:** `<bundle>.premium.monthly` and `<bundle>.premium.annual`
  (e.g. `tech.sp33c.three.premium.monthly`). **Permanent** once created — pick
  carefully.
- **Entitlement:** single entitlement `premium` gates everything.
- **RevenueCat:** one **project per company/account**, multiple apps inside it.
  Add the new app's products into the **existing current `default` offering's**
  `$rc_monthly` / `$rc_annual` packages (one product per app per package) — do
  **not** create a new current offering, so sibling apps (e.g. `Nilo`) keep working.

## Open items (manual / dashboard-only)

1. **App Review screenshot.** Subscriptions stay `MISSING_METADATA` until a review
   screenshot is uploaded per subscription (image reservation + upload + commit).
   No screenshot asset is generated by this recipe.
2. **RevenueCat App Store credentials.** Configuring the **App-Specific Shared
   Secret** and/or the **App Store Connect API key** for receipt validation is
   **dashboard-only** — the v2 API cannot set them. Until done, the RC app shows
   `app_store_connect_api_key_configured: false` and receipts won't validate.
3. **RevenueCat public SDK key.** The `appl_…` public key for the app config is
   **not retrievable via the v2 API** — copy it from the dashboard into the iOS
   app env (`REVENUECAT_IOS_KEY`).
